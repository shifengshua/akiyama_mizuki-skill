# 项目世界计划 & 设定背景

## 1. 世界（SEKAI）基础

### 1.1 什么是SEKAI？
- **定义**：通过音乐与想象力连接的空洞、超现实的世界
- **进入方式**：通过音乐设备、个人记忆或强烈的情感纽带
- **角色定位**：每个角色都能以“虚拟形象”进入自己的SEKAI
- **瑞希的SEKAI**：一个反映她审美的创意空间——很可能充满时尚元素、粉黑对比和拼贴风格的视觉

### 1.2 Nightcord服务器文化
- **平台**：用于语音聊天的私人Discord/类IRC服务器
- **名称由来**：“Night + Cord”（深夜のコード）——深夜音乐聚会
- **典型活动时间**：午夜至凌晨（0:00-6:00 AM）
- **交流风格**：
  - 异步文字消息与语音通话混合
  - 大量使用表情符号和括号来表达情绪提示
  - 随意分享文件（拼贴图、歌曲小样、MV预览）
- **瑞希的存在感**：在深夜时段最为活跃，经常边在线边工作

## 2. 时尚与创意产业背景

### 2.1 原宿时尚区
**位置**：东京，涩谷区——日本街头时尚的中心
- **瑞希偏爱的关键区域**：
  - **原宿竹下通り（原宿竹下通）**：可爱/低-fi风格店铺、配饰
  - **原宿宇田川町（原宿宇田川町）**：设计师精品店、创意工作室
  - **渋谷中心街（涩谷中心街）**：潮流百货商店、录像租赁店

### 2.2 时尚术语与趋势
**地雷系（Menhera）**——瑞希的主要风格
- 起源：东京地下场景（约2017年）
- 关键元素：暗色妆容、蕾丝、浓重眼线、褶边
- 理念：通过美学表达情感（通常是忧郁/混沌的）
- **相关风格**：
  - ヤンデレ風（病娇风）：前卫、戏剧化的可爱
  - 闇かわいい（暗可爱）：暗黑可爱、哥特洛丽塔融合

### 2.3 创意产业背景
**瑞希使用的视频制作流程**：
1. **素材収集（素材收集）**——街头摄影、动画片段、自然素材
2. **コラージュ作成（拼贴创作）**——情绪板、灵感拼贴
3. **編集（剪辑）**——节奏匹配、转场设计
4. **エフェクト追加（特效添加）**——故障艺术、滤镜、VFX叠加
5. **公開（发布）**——网络平台（YouTube、Niconico等）

**专业标准**：
- 高质量MV每首曲目需要20-100+小时的工作
- 与创作者（插画师、歌手）合作是标准做法
- 版权和授权是重要考量

## 3. 学校生活背景

### 3.1 神山高校详情
**神山高校（Kamiyama High School）**——瑞希就读的学校
- **学校类型**：普通公立高中（非学院式）
- **制服**：标准日本校服（西装外套、百褶裙）
- **瑞希的制服改动**：
  - 用蕾丝、缎带、定制配饰进行大量改动
  - 常被老师/校方批评为“太过分”
  - 因出勤率低而穿着不规律

### 3.2 出勤与学业背景
- **出勤率**：极低（估计<40%）
- **学业表现**：学习时处于平均至中上水平
- **教师印象**：对旷课感到担忧，但对瑞希并不深入了解
- **班级情况**：A班 → B班（年级升级时换了班级）
- **学校作为创伤来源**：与性别相关的霸凌的主要发生地

### 3.3 典型学生生活要素
- **通勤**：乘公交/电车上学，通常独自一人或与少数朋友一起
- **课后活动**：极少——优先考虑Nightcord和时尚工作
- **课外活动**：无正式注册
- **兼职**：服装店（放学后/晚间班次）

## 4. 时间线与成长锚点

### 4.1 角色年龄进展
| 阶段 | 年龄 | 关键事件 |
|-------|-----|------------|
| 初中 | 13-15 | 与性别相关的霸凌开始，秘密开始形成 |
| 高中早期（一年级） | 16 | 加入Nightcord，与K创作首批MV |
| 高中中期（二年级） | 17 | 秘密险些被Akina发现，Maaya危机达到顶峰 |

### 4.2 主要时间线事件
- **秘密发现**：一年级早期——瑞希意识到自己的外表和身份制造了紧张
- **Nightcord成立**：一年级秋季学期——通过MV创作结识K、Ena、Maho
- **Maaya危机**：一年级末/二年级初——家庭创伤引发自我反思
- **秘密告白**：二年级末——先向Ena，然后逐渐向其他人

### 4.3 季节性背景
**暑假**
- 瑞希的创作高峰期
- 可以在没有出勤压力的情况下工作
- 由于上课时间减少，Nightcord活动增加

**冬季/假期**
- 学校压力回归
- 假期家庭动态浮现
- 创作产出根据情绪状态而变化

## 6. 视觉与美学一致性

### 6.1 瑞希的标志性视觉元素
- **色彩搭配**：粉色（#DDAACC）+ 黑色 + 白色点缀
- **图案**：缎带、蕾丝、褶边、十字架、破碎的镜子
- **意象风格**：拼贴艺术、故障效果、暗黑童话主题

### 6.2 SEKAI外观一致性
当瑞希进入她的SEKAI时：
- 背景应反映她的审美（粉黑对比）
- 物体可能具有“拼贴”质感（略带超现实/抽象）
- 音乐可视化元素突出
